# BACKROW 11.0 — Submission / Exhibition Checklist

## Rules
- [ ] Recheck official YCWC page and current Indonesia/local guidebook on submission day.
- [ ] Confirm Senior eligibility, AI-integrated website format, originality, deadline, hosted/source requirements, presentation duration, and language.

## Source/release
- [ ] Use only the final SHA-256-locked ZIP.
- [ ] Clean-extract it into a new directory.
- [ ] Run setup from scratch.
- [ ] Verify source/PDF upload, camera/photo path, judge demo, fix/rescan, whole-deck matching, study pages, validation console.
- [ ] Confirm no credentials, raw participant data, stale model, `__pycache__`, or `.pyc` files.

## Physical evidence
- [ ] Complete ≥3 rooms if feasible.
- [ ] Cover near/mid/far positions.
- [ ] Use multiple display/projector/camera conditions.
- [ ] Run naïve timed reader studies.
- [ ] Keep calibration and locked studies separate.
- [ ] Export `BACKROW_WORKFLOW.json`.
- [ ] Export `BACKROW_DECK_MATCH.json`.
- [ ] Run locked evaluator.
- [ ] Preserve failing results if any.
- [ ] Run frontier multimodal baseline on the same frozen evidence.

## Presentation
- [ ] Use the supplied competition deck as the starting deck.
- [ ] Replace any “current” result with the actual locked physical result once available.
- [ ] Never call procedural AudienceNet F1 human accuracy.
- [ ] Have live judge-input mode ready.
- [ ] Have deterministic backup case ready.
- [ ] Preflight exact projector/camera/browser device.
- [ ] Cache/localize all required runtime assets.
- [ ] Rehearse 60-second capability demo.
- [ ] Rehearse Q&A answers without marketing language.

## Claim discipline
- [ ] Do not say “world first.”
- [ ] Acknowledge 2011 lecture-hall legibility prior art.
- [ ] Acknowledge 2017 projector-camera quality prior art.
- [ ] Acknowledge source-file readability competitors.
- [ ] State camera ≠ human eye.
- [ ] State exactly which model was trained by the project.
- [ ] State which components are third-party/classical.
- [ ] Report real sample sizes and confidence intervals.
