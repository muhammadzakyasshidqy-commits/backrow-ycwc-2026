# BACKROW 11.0 — Checklist Submission / Exhibition Bahasa Indonesia

## Aturan
- [ ] Cek ulang situs resmi YCWC dan guidebook Indonesia/daerah pada hari submission.
- [ ] Pastikan kategori Senior, format AI-integrated website, originality, deadline, hosted/source requirement, durasi presentasi, dan bahasa.

## Source / release
- [ ] Gunakan hanya ZIP final yang SHA-256-nya dikunci.
- [ ] Extract ke folder baru.
- [ ] Jalankan setup dari nol.
- [ ] Uji source/PDF upload, kamera/foto, judge demo, fix/rescan, whole-deck matching, study pages, dan validation console.
- [ ] Pastikan tidak ada credential, data peserta mentah, model lama, `__pycache__`, atau `.pyc`.

## Bukti fisik
- [ ] Selesaikan ≥3 ruangan jika memungkinkan.
- [ ] Cover posisi dekat/tengah/jauh.
- [ ] Gunakan beberapa kondisi projector/display/camera.
- [ ] Jalankan studi pembaca naïve dengan timed exposure.
- [ ] Pisahkan calibration dan locked study.
- [ ] Ekspor `BACKROW_WORKFLOW.json`.
- [ ] Ekspor `BACKROW_DECK_MATCH.json`.
- [ ] Jalankan locked evaluator.
- [ ] Simpan hasil gagal apa adanya.
- [ ] Jalankan baseline multimodal frontier dengan evidence frozen yang sama.

## Presentasi
- [ ] Pilih deck EN atau ID sesuai tahap lomba.
- [ ] Ganti placeholder result dengan hasil locked fisik aktual setelah tersedia.
- [ ] Jangan menyebut procedural AudienceNet F1 sebagai human accuracy.
- [ ] Siapkan live judge-input mode.
- [ ] Siapkan deterministic backup case.
- [ ] Preflight projector/camera/browser yang benar-benar dipakai.
- [ ] Latih demo capability 60 detik.
- [ ] Latih Q&A tanpa marketing language.

## Disiplin klaim
- [ ] Jangan berkata “world first”.
- [ ] Akui prior art lecture-hall legibility 2011.
- [ ] Akui prior art projector-camera quality 2017.
- [ ] Akui source-file readability competitors.
- [ ] Tegaskan kamera ≠ mata manusia.
- [ ] Sebutkan model yang memang dilatih proyek.
- [ ] Pisahkan komponen third-party/classical.
- [ ] Laporkan sample size dan confidence interval yang benar-benar dihitung.
