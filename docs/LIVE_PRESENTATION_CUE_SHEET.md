## 2. Exact failure

Ask the judge to choose a slide. Show automatic page matching, rectification, and localized evidence. Avoid claiming human eyesight accuracy.

## 4. AI architecture

## 5. Fix → rescan
Repair the exact source region. Keep the audience position fixed. Rescan and show the risk disappearing.

## 6. Scientific boundary
State clearly that camera evidence is not a human eye. Point to the locked human-study path if asked for human validation.

## 7. Close
`A presenter sees the source file. The audience sees the room. BACKROW tests the room. Please choose a slide.`

## Failure fallback
If live camera/network permission fails, use the bundled judge case. Say it is the deterministic backup and do not present it as a live room capture.
